# 🚣 Jordan's Rowing Journey Tracker - iPhone PWA Version

A Progressive Web App (PWA) version of the rowing tracker, optimized for iPhone and mobile devices.

## 📱 Features

- **Installable**: Add to iPhone home screen for app-like experience
- **Offline Capable**: Works without internet (maps need connection)
- **Mobile Optimized**: Responsive design for iPhone screens
- **All Original Features**: Same functionality as desktop version

## 🚀 Quick Start

1. **Generate Icons**: Open `ICON_GENERATOR.html` in your browser and click "Generate All Icons"
2. **Move Icons**: Place all generated icon files in the `icons/` folder
3. **Deploy to GitHub**: Follow the detailed instructions in `GITHUB_SETUP_INSTRUCTIONS.md`

## 📂 Files Included

- `index.html` - Main app file (updated with PWA meta tags)
- `app.js` - Application logic
- `styles.css` - Styling
- `manifest.json` - PWA manifest (defines app metadata)
- `service-worker.js` - Enables offline functionality
- `ICON_GENERATOR.html` - Tool to generate app icons
- `GITHUB_SETUP_INSTRUCTIONS.md` - **READ THIS FIRST!** Complete step-by-step setup guide
